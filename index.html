MediEdge: A low-cost edge-based cyber-physical IoT platform for real-time remote patient monitoring with comparative validation

MediEdge is a low-cost remote patient-monitoring platform developed using an ESP32-based embedded architecture and physiological sensors. The system explores local acquisition and processing of vital-sign data with secure cloud synchronization.

$34.50Reported bill of materials
2.88 bpmHeart Rate MAE (ICC: 0.961)
2.12%SpO₂ MAE (ICC: 0.786)
2000Paired prototype-reference observations

System Architecture & Hardware

  • Dual-core ESP32 with FreeRTOS task separation.
  • AD8232 single-lead ECG sensor and waveform processing.
  • MAX30100 for PPG-based heart rate and SpO₂.
  • DS18B20 body-temperature sensing and DHT11 ambient monitoring.
  • Encrypted cloud synchronization using AES-256-CBC and HMAC-SHA256.

Key Engineering Results

  • 250 Hz ECG sampling with 2.3s end-to-end latency.
  • 98.7% cloud synchronization success.
  • 12.6-hour continuous battery operation (5000 mAh).
  • MicroSD card buffering for extended offline data continuity.
  • Demonstrated edge resilience under tested intermittent connectivity.
Publication Reference: Shil, A., Mohajan, J., & Islam, A. J. (2026). Measurement (Elsevier), Vol. 292, Article 123099. DOI: 10.1016/j.measurement.2026.123099

LifeTrack: A Low-Cost Edge-First Wearable IoT Platform with Measured Cryptographic Overhead and Edge-Resilience for Real-Time Health Monitoring and Fall Detection

LifeTrack is a low-cost wearable health-monitoring prototype built around a dual-core ESP32. It combines physiological sensing, motion-based fall detection, local edge processing, and GSM emergency communication. The design aims to remain useful when Wi-Fi or internet connectivity is unavailable.

$45Reported bill of materials
5,000Reported adult volunteers in validation
18 mWMeasured encryption power overhead
9.4 sFall-alert time with Wi-Fi disabled

System architecture

  • Dual-core ESP32 with FreeRTOS task separation.
  • Local web dashboard hosted on the device for offline access.
  • GSM-based SMS/voice emergency alerting independent of Wi-Fi.
  • AES-256-CBC encryption for data before cloud transmission.

Hardware components

  • MAX30100 — heart rate and SpO₂ sensing.
  • MPU6050 — acceleration and angular-motion sensing.
  • MLX90614 — non-contact temperature sensing.
  • NEO-6M — GPS positioning.
  • SIM800L — GSM communication.

Industrial Safety · Wearable IoT · LoRa Communication · Firebase Cloud

SafeGuard: IoT-Based Smart Safety Vest and Smart Helmet System for Industrial Worker Safety Monitoring

SafeGuard addresses multiple threats in high-risk industrial environments (falls, toxic gases, heat stress) by integrating a smart helmet and smart vest. It utilizes an ESP32, LoRa for long-distance blind-spot coverage, and Firebase for real-time cloud monitoring, creating a comprehensive "human-environment-equipment" safety net.

Dual-DeviceHelmet + Vest Collaboration
LoRa + Wi-FiHybrid Communication
Multi-SensorGas, HR, IMU, Temp
PiezoelectricEnergy Harvesting Design

System Architecture

  • ESP32 dual-core processing for sensor threshold logic and local alerts.
  • LoRa for long-distance transmission in poor 4G/5G industrial sites.
  • Wi-Fi gateway syncing LoRa data to Firebase Realtime Database.
  • Piezoelectric energy harvesting for sustainable low-power operation.
  • Mobile App & Website (Flutter) for real-time supervisor dashboards.

Hardware Components

  • Smart Helmet: MPU6050 (fall/impact), MQ-135 (gas), DHT22 (temp), IR/FSR (wear detection).
  • Smart Vest: Heart rate sensor (fatigue monitoring), additional accelerometers (posture).
  • Alerts: Local buzzer and LED indicators triggered by threshold violations.
Research contribution: Integrates environmental perception (helmet) with physiological monitoring (vest) using a hybrid LoRa/Firebase architecture to provide real-time proactive warnings in network-constrained industrial environments.
